To use this project:
-Add the following to the configuration:
    -'ConnectionStrings:MariaDB': a connection string to MariaDB
    -"R2": {
        "AccountId": "",
        "AccessKeyId": "",
        "SecretAccessKey": "",
        "BucketName": "",
      }
-call AddVehicleSales on the service collection
-it depends on the UserIdentity.User entity/table existing.
